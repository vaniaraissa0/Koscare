# KosCare — Sistem Pelaporan & Pemantauan Kerusakan Fasilitas Kos

> **"Hunian Nyaman, Perbaikan Terpantau"**  
> Dibuat untuk keperluan tugas kuliah menggunakan arsitektur **PHP Native (PHP 8.3+)** dan **MySQL/MariaDB**, siap dijalankan di lingkungan lokal **XAMPP Windows**.

Seluruh file kode sumber PHP Native untuk XAMPP terletak di dalam folder **`koscare/`**. Anda dapat menyalin folder tersebut ke `C:\xampp\htdocs\koscare\` atau menggunakan tombol **Unduh File XAMPP (.zip)** pada aplikasi live preview.

Silakan baca dokumentasi lengkap di:
- [Petunjuk Instalasi & Troubleshooting XAMPP](koscare/README.md)
- [Skrip Database MySQL](koscare/database/koscare.sql)
- [Skrip Setup Pengelola Vania Raissa](koscare/setup/create_admin.php)
